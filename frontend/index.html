Documentação das APIs

A Aethra expõe rotas HTTP simples para outros sistemas consumirem recursos de GenAI. No ambiente público atual, a API está aberta: basta enviar JSON para o endpoint desejado.

Endpoint base https://viniciuskhan-aethra.hf.space

/health

Verifica se a API está online, qual provider está ativo e quais modelos estão configurados.

Invoke-RestMethod -Uri "{{API_URL}}/health"
POST

/chat

Geração de texto e conversa com o modelo principal.

{
  "pergunta": "Explique o que é NPS.",
  "temperatura": 0.2,
  "max_tokens": 300
}
POST

/summarize/email

Resumo especializado de e-mails com assunto, remetente, corpo e instruções opcionais.

{
  "assunto": "Cobrança duplicada",
  "remetente": "cliente@empresa.com",
  "corpo": "Texto completo do e-mail...",
  "instrucoes": "Informe prioridade e próxima ação."
}
POST

/vision

Envia imagem em base64 para análise multimodal com o modelo visual configurado.

{
  "imagem_base64": "BASE64_DA_IMAGEM",
  "imagem_media_type": "image/jpeg",
  "prompt": "Descreva a imagem."
}

Fluxo recomendado

1. Envie JSON 2. Aethra chama Ollama 3. Modelo responde 4. Sua aplicação usa o resultado
Exemplo completo: resumo de e-mail

Resposta padrão

{
  "status": "ok",
  "model": "llama3.2:3b",
  "resposta": "Texto gerado pelo modelo...",
  "metadados": {
    "provider": "ollama"
  }
}
